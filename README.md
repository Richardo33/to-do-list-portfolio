# Workgroup Navigation (WGN)

Workgroup Navigation (WGN) is a task management web app that provides a Kanban-style board with draggable tasks across columns like To Do, In Progress, and Done, built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Kanban board with multiple columns  
- Drag and drop tasks between columns  
- Create, edit, and delete tasks  
- Simple, clean, responsive UI  
- (Optional) AI-assisted task descriptions, if configured  

## Tech Stack

- Next.js (React + TypeScript)  
- Tailwind CSS / shadcn-ui  
- State management (e.g. Zustand / Redux – adjust to actual implementation)  

## Getting Started

- Node.js LTS
